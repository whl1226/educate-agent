# 教师办公文档生成（Office Agent）设计文档

> 日期：2026-08-15 ｜ 状态：已确认 ｜ 关联：乡芽 Agent 工作台（agent.html + LangGraph 编排）

## 1. 目标

教师通过 Agent 工作台自然语言指令，一键生成 **Word / PPT / PDF / Excel** 办公文档：教案、试卷、发言稿、微课脚本、课件、学情报告、成绩单等，下载即用。

## 2. 架构（统一中间格式，对齐开源生态）

```
LLM 输出：Markdown 正文 + YAML 元数据头（唯一内容规范，LLM 最擅长的输出格式）
  │
  ▼ ① md-validator（三层校验 + 转 IR）
   结构校验（YAML 头 schema）→ 语法校验（markdown-it 解析）→ 安全校验（HTML/URL/大小）
   → 输出统一 IR（heading/paragraph/list/table/code 文档树）
  │
  ▼ ② office.service（渲染核心）
   ├─ docx-renderer（docx 包）  → .docx
   ├─ pptx-renderer（pptxgenjs）→ .pptx（标题页 + 按 ## 分页）
   ├─ pdf-renderer（pdf-lib + simhei.ttf 嵌入）→ .pdf
   └─ xlsx-renderer（exceljs）  → .xlsx
  │
  ▼ ③ 文件落盘 + files 表登记 → 下载走现有鉴权通道 GET /files/:id/download
```

**借鉴开源**：markdown-docx（MD→DOCX）、dom-to-pptx / dashi-ppt-skill（HTML→PPTX/PDF 多格式导出）、kordoc（Markdown 为通用中间格式）。

## 3. Markdown 中间格式约定

```markdown
---
title: 五年级语文《草船借箭》教案
format: docx            # docx | pptx | pdf | xlsx
theme: forest           # 可选主题色
author: 王秀兰          # 可选
---

# 一、教学目标
...
```

## 4. 校验规则（三层防线，用户重点要求）

| 层 | 规则 | 失败行为 |
|---|---|---|
| ① 结构 | YAML 头可解析；title 必填≤80字；format∈白名单；theme∈白名单；未知字段拒绝 | 结构化错误返回 Agent，自愈重试 ≤2 次 |
| ② 语法 | markdown-it 零异常；代码块闭合；表格列数一致；标题层级≤4；列表嵌套≤5；段落数≤200 | 同上（带行号+修复建议） |
| ③ 安全 | 剥离 HTML 标签（防 OOXML 注入）；URL 仅 http/https；正文≤20KB；表格≤10列、单元格≤200字 | 同上 |

校验错误结构：`{ valid:false, errors:[{ code, line, message, fix }] }`

## 5. 工具接入

- ToolRegistry 注册 **`generate_document`**（权限：teacher/admin）：`{ format, title, content_md, theme? }`
- AgentService binding：校验→渲染→落盘→返回 `{ fileId, filename, downloadUrl, format }`
- 系统提示新增规则：文档类任务必须调用 generate_document；content_md 用 Markdown 语法（含 YAML 头）
- 前端 done 事件渲染下载链接（renderDone 增加文件卡片）

## 6. 渲染器设计要点

| 渲染器 | 库 | 关键点 |
|---|---|---|
| docx | `docx` 9.x | IR→Paragraph/Table/Heading；中文宋体；表格边框；标题样式 |
| pptx | `pptxgenjs` 4.x | 首页标题；## 标题分页；要点列表；表格页；主题色 |
| pdf | `pdf-lib` 1.17 | **嵌入 simhei.ttf 字体**（C:\Windows\Fonts\simhei.ttf）；分页；表格绘制 |
| xlsx | `exceljs` 4.x | 表头样式；列宽自适应；数据行 |

## 7. 目录结构

```
server/src/modules/office/
  office.module.ts        # 注册 + 依赖注入
  office.service.ts       # generateDocument()：校验→渲染→落盘→登记
  md-validator.ts         # 纯函数：三层校验 + markdown→IR
  office.types.ts         # IR 类型 + 校验错误类型 + 渲染器接口
  renderers/
    docx-renderer.ts
    pptx-renderer.ts
    pdf-renderer.ts
    xlsx-renderer.ts
  __tests__/              # 各模块单测
```

## 8. 安全与合规

- 文件落盘：`uploads/office/`（UUID 重命名，防路径遍历）；files 表登记（sha256/magic 校验走现有 files.service 逻辑）
- 下载鉴权：复用 `GET /files/:id/download`（归属校验）
- 内容消毒：HTML 剥离、URL 白名单、大小限制（防 Prompt 注入恶意 OOXML）
- 演示合规：演示数据角标延续；生成文档标注来源
