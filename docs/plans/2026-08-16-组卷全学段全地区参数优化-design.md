# 组卷参数优化：全学段 × 全地区（对标学科网颗粒度）— 设计方案

> 日期：2026-08-16 · 状态：待确认
> 目标：把组卷参数区从「硬编码演示下拉」升级为「全学段、全教材版本、可按章节/知识点选题」的真实可用链路。
> 约束：UI 改动收敛在 `#page-paper` 参数卡内，其余页面零改动；不引入新框架；数据采用「课标统一知识点 + 版本映射」架构、主版本先行。

| 现状 | 证据 |

**结论**：需求（"选知识点→组卷"，见 `docs\演示脚本.md:17`）与实现存在直接矛盾，需全链路打通。

## 2. 总体架构：三层模型

```
第 1 层  学段学科维度    学段(小学/初中/高中) → 年级(1-12) → 学科(9-12科)
第 2 层  课标知识图谱    学科 → 主题/领域 → 知识点 → 子知识点（版本无关，权威基准）
                        数据源：2022版义教课标 + 2017版高中课标
第 3 层  教材版本目录    教材版本(人教/北师大/苏教/外研/教科版…) → 册 → 章 → 节
                        每节映射到课标知识点（textbook_kp_mapping）
```

**为什么这是"全中国全地区"的正解**：知识点只建 1 套（课标级，全国教材统一遵循），地区差异只体现在第 3 层目录组织；出题/学情/跨版本对比均锚定课标知识点。统编科目（语文/道法/历史）天然全国一版，映射成本最低。

## 3. 颗粒度：对标学科网双选题通道

| 通道 | 层级颗粒度 | 数据来源 |
|---|---|---|
| **章节选题** | 教材版本 → 册(七上/五下) → 章(第1章 有理数) → 节(1.1 正数和负数) | `textbook_catalog` 目录树 |
| **知识点选题** | 学科 → 主题/领域 → 知识点 → 子知识点（题目标签粒度） | `curriculum_tree` 课标考点树 |

**题目标签**：知识点(最细级) + 题型(单选/多选/填空/解答/判断) + 难度(容易0.8/较易/一般/较难/困难0.2) + 年份 + 来源(教材/真题/名校/自建)。

**出卷方式**：
- **关联出题**：每题至少含 1 个选中知识点，允许含其他章节知识点
- **综合性选题**：只含选中知识点

## 4. 数据模型

| 表 | 说明 | 关键字段 |
|---|---|---|
| `curriculum_tree` | 课标知识点树（多级父子） | `id/subjectId/parentId/name/level/stageRange/curriculumSource/order` |
| `textbook_versions` | 教材版本表 | `id/name/publisher/region/stage/curriculumBasis` |
| `textbook_catalog` | 版本→册→章→节目录 | `id/versionId/parentId/type(册\|章\|节)/name/grade/semester/order` |
| `textbook_kp_mapping` | 节 ↔ 知识点映射 | `id/textbookNodeId(节)/knowledgePointId` |
| `questions` 扩展 | 题目标签补齐 | 新增 `difficulty(0-1)/type/source/year` |
| `QuestionPaper` 扩展 | 组卷快照 | 新增 `stage/grade/versionId/chapterIds/knowledgePointIds` |

> 现有 `knowledge_points` / `textbook_contents` 表按上述模型演进改造（迁移/替换二选一，实现时定）。

## 5. 后端 API

**新增目录查询 API**（`knowledge` 模块新增 controller）：

| 端点 | 返回 |
|---|---|
| `GET /knowledge/stages` | 学段列表 |
| `GET /knowledge/grades?stage=` | 年级列表 |
| `GET /knowledge/subjects?stage=&grade=` | 学科列表 |
| `GET /knowledge/versions?subject=` | 教材版本列表 |
| `GET /knowledge/books?versionId=` | 册列表 |
| `GET /knowledge/catalog?bookId=` | 该册「章→节」树 |
| `GET /knowledge/kp-tree?subject=&stage=` | 课标知识点树 |
| `GET /knowledge/kp-by-chapter?chapterIds=` | 章节反查知识点 |

**组卷接口改造**（`POST /ai/paper/generate` 入参增加）：
```
{ stage, grade, subject, bookVersionId, bookId,
  chapterIds[], knowledgePointIds[], outMethod: 'assoc'|'strict',
  choice/blank/solve, layerMode, difficulty? }
```

**出题逻辑修复**：
1. 按 `knowledgePointIds`（未选则用 `chapterIds` 反查）过滤题库，不再轮询硬编码池
2. 无题兜底：标注"该知识点暂无题库，已交 AI 现场生成"，复用现有 AI 生成链路
3. `generate_paper` 工具 schema 同步加字段，LLM 模式也能按知识点出题
4. 导出预览带知识点标签

## 7. 数据管线与首发范围

**目录结构**（`server/src/db/seeds/textbook/`）：
```
grades.json / subjects.json / versions.json
catalog/{publisher}/{subject}/{book}.json     # 册→章→节
knowledge/{subject}.json                      # 课标知识点树
questions/{subject}.json                      # 题目（挂知识点/难度/题型/来源/年份）
```
统一由 `run-seed.ts` 加载；后续 AI 生成 + 人工审核补全走同格式。

**首发范围**：小学/初中/高中各选 2 个年级 × 语数英 +（初中加物理/化学、高中加物理/化学/生物），每科 1-2 个主流版本主干目录；知识点树每科 2-3 级主干；每知识点 ≥1 题。
