### 2.1 前端增量改造机制（核心设计）

**原则：原型 HTML 文件的 DOM/CSS 视觉零改动；交互代码分层接管。**

1. **内联脚本抽取**：构建时把 4 个 HTML 的内联 `<script>` 块抽出为 `assets/legacy/*.legacy.js`，HTML 中替换为 `<script src="...">`（视觉无影响）。→ 这是启用 CSP `script-src 'self'` 的前提（安全约束）。
2. **onclick 迁移**（需用户确认，见 §8.2）：legacy.js 末尾追加行为迁移段：遍历 `[onclick]` 元素，记录函数名与参数，`addEventListener` 绑定 `window[fn]`。DOM 上的 onclick 属性保留原样（CSP 会拦截其执行，由 addEventListener 接管，行为等价）。→ 视觉结构零改动，CSP 可严格化。
3. **全局函数覆写**：TS 入口模块（`type=module`，晚于 legacy 执行）覆写 `window.toast / startGenerate / showPage / go / recordVoice / ...` 等为真实接口驱动版本；legacy 的初始渲染（向导列表等）保留，其数据常量（SKILL_LIST 等）由 TS 模块注入真实数据源版本。
4. **数据区刷新**：TS 模块加载后调用各页面数据接口，重写写死数字（KPI、图表序列、列表）——通过接口返回的 JSON 渲染，图表用 ECharts 现有实例 `setOption` 更新。
5. **新增页面**：仅新增 `login.html`（登录/找回密码/强制下线提示），样式沿用原型设计语言（CSS 变量一致）。

**TS 分层模块（src/frontend 编译到 public/assets）**：

```
core/
  request.ts     fetch 封装：credentials:include、CSRF 头注入、超时、错误码标准化、
                 401 静默刷新重放队列、防重复提交（进行中请求合并）、幂等键生成
  auth.ts        登录/登出/会话信息、token 刷新、异地登录事件
  guard.ts       路由守卫：未登录→login.html，角色不符→403 页，登出重定向
  ui.ts          toast/loading/错误提示接入原型既有 #toast 组件、防抖节流工具
  state.ts       轻量全局状态（当前用户、未读数、角色）
  xss.ts         escapeHtml / safeInject（配合 DOMPurify 白名单过滤富文本）
  validate.ts    表单校验（邮箱/手机/密码强度/必填），仅体验层
  perf.ts        懒加载（按页动态 import 逻辑）、请求缓存、列表虚拟滚动
modules/
  auth-page.ts   登录页逻辑（验证码、错误锁定提示、无感续期）
  teacher-*.ts   教师端各页面逻辑（按 data-page 拆包，动态 import 懒加载）
  student-*.ts   学生端各视图逻辑
  parent-*.ts    家长端各视图逻辑
  admin-*.ts     管理端各页面逻辑
```

构建：Vite（仅作为 TS→ES2020 打包器，public 目录直出，不接管 HTML 结构）。

## 3. 数据库表结构（SQLite + TypeORM）

> 约定：`users` 为四端统一账号表（role 区分）；全部表含 `created_at/updated_at/deleted_at`（软删除）；外键列全部建索引；时间统一 `datetime('now')` ISO8601 文本；JSON 字段存 TEXT。
> 核心闭环：`answer_records`（D6 唯一原生行为源）→ `mastery_snapshots` → 个人/班级/区域三级上卷视图。

### 3.1 认证与会话（6 表）

## 5. 鉴权与安全整体方案

### 5.1 认证与会话

| 机制 | 设计 |
|---|---|
| 密码存储 | bcrypt（cost=12）加盐哈希；禁用明文/无盐；密码策略 ≥10 位含大小写+数字 |
| 凭证载体 | **Access Token：JWT 15 分钟（内存/会话期），Refresh Token：服务端持久化（sessions 表仅存哈希）、HttpOnly + Secure + SameSite=Lax Cookie，7 天**；严禁 localStorage/sessionStorage 存任何凭证 |
| 无感续期 | 前端 401 拦截 → 静默调 /auth/refresh（Cookie 自动携带）→ 失败重放队列（并发请求合并）；refresh 轮换 + 旧 token 复用检测（检测到复用即吊销该用户全部会话） |
| 主动登出 | 吊销当前 refresh token + 前端清内存凭证 |
| 强制下线 | admin 调 /auth/force-logout/:userId → 吊销该用户全部会话 → 该用户下次请求 40103 → 前端弹"已被强制下线"并跳登录 |
| 异地登录检测 | 每次登录记录 device_name/ip/ua/fingerprint（SHA-256 指纹）；与历史会话指纹不一致 → 写入 notifications"新设备登录提醒"，会话列表标"异地"；支持一键踢除旧会话；可配置"单设备模式" |
| 暴力破解防护 | Redis 滑动窗口：每 IP 5 次/15min 失败触发验证码 + 临时锁定 15min；账号维度 5 次失败锁定 30min（login_fail_count + locked_until）；登录接口全局限流 10 req/min/IP |
| 验证码 | 图形验证码（算术+干扰），Redis TTL 5min，一次性；登录失败 ≥3 次后强制要求 |
| 密码重置 | 需验证码 → 生成一次性 token（15min，仅存哈希）→ 重置链接使用后即焚（used_at 标记 + Redis 去重） |
| 密码修改 | 需旧密码校验；修改后吊销其他设备会话 |

### 5.2 传输与重放防护

| 机制 | 设计 |
|---|---|
| HTTPS+HSTS | Nginx 强制 443 + HSTS（max-age=31536000; includeSubDomains） |
| CSRF | 双提交 Cookie（登录时下发 `XSRF-TOKEN` Cookie + 前端请求头 `X-CSRF-Token` 回显）+ SameSite=Lax + NestJS 全局 CSRF 守卫校验 Origin/Referer；所有写操作（POST/PUT/PATCH/DELETE）强制 |
| 防重放 | 高风险接口（登录/重置密码/踢出/预警处置）：校验 `X-Timestamp`（±5min）+ `X-Nonce`（Redis 一次性，TTL 10min）；生成类接口幂等键（Idempotency-Key） |
| 全局限流 | @nestjs/throttler + Redis：IP 100 req/min、用户 300 req/min；登录/验证码/重置接口独立严格配额 |

### 5.3 前端安全

| 机制 | 设计 |
|---|---|
| XSS | 全域转义工具（escapeHtml）用于所有动态注入；富文本（教案/评语/周报寄语等）统一走 DOMPurify 白名单过滤（禁 script/iframe/on* 事件/style 含 url()）；**服务端同步做输出清洗（二次防线）**；禁用 eval/new Function |
| CSP | `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https://code.iconify.design; font-src 'self' https://fonts.gstatic.com https://fonts.googleapis.com; connect-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'`（内联样式保留因为原型大量 style 属性——CSS 注入风险低且可控；内联脚本已抽取为外部文件；onclick 由迁移机制接管） |
| 点击劫持 | X-Frame-Options: DENY + CSP frame-ancestors 'none' 双保险 |
| 路由守卫 | 前端 guard 检查登录态/角色/数据范围；按钮隐藏仅视觉优化，后端全量校验 |
| 凭证安全 | 前端不打印/不存储账号密钥隐私数据；console 拦截器屏蔽敏感字段 |

### 5.4 后端接口安全

| 机制 | 设计 |
|---|---|
| RBAC | 角色（admin/teacher/student/parent）+ 权限码表（如 `lesson:create`、`class:view`）；全局 RolesGuard + PermissionsGuard（装饰器声明） |
| 水平越权 | 每个业务 Service 强制归属校验：教师只能操作 `teacher_class_links` 中的班级；学生只能访问本人数据；家长只能访问绑定孩子（student_parent_links）；admin 按 region 范围 |
| SQL 注入 | TypeORM 参数化查询全覆盖；禁止拼接 SQL |
| 输入校验 | 全局 ValidationPipe（whitelist+forbidNonWhitelisted）；DTO 白名单；校验错误码 40001；**所有 AI 生成结果做 schema 校验** |
| 命令/模板注入 | 不执行系统命令；模板引擎仅用静态模板（无用户输入拼接执行）；路径处理白名单 |
| 异常处理 | 全局 ExceptionFilter：对外仅标准化错误码+脱敏 message；堆栈/DB 详情仅写服务端日志（日志脱敏拦截器） |
| 文件上传 | 后缀白名单（jpg/png/gif/webp/pdf/doc/docx/xls/xlsx/mp3/wav/mp4/zip）+ MIME 校验 + **文件魔数校验**（JPEG/PNG/PDF/MP3/WAV 头字节）；UUID 重命名防路径遍历；大小上限（图片 10MB/音频 20MB/文档 30MB）；存储于 /uploads/分类/ 独立目录；**部署时独立资源域名**（uploads.example.com，Nginx 独立 server 块） |
| 敏感输出 | 手机号/身份证等 mask 工具（138****1234 / 3***************X）；接口 DTO 白名单字段（永不含 password_hash） |

### 5.5 数据与网络安全

| 机制 | 设计 |
|---|---|
| 数据最小化 | 采集仅业务必需字段；学生端不采集位置/通讯录等；家长授权记录在周报数据血缘（auth_note） |
| 审计日志 | 关键操作留痕，detail 字段存储**脱敏版**（手机号掩码、不存密码/Token）；日志轮转 |
| 安全响应头全集 | `X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`Permissions-Policy: camera=(), microphone=(self), geolocation=()`、`X-Frame-Options: DENY`、`Strict-Transport-Security`、CSP；隐藏 `Server`/`X-Powered-By` 版本信息（Nginx `server_tokens off` + NestJS 移除 X-Powered-By） |
| 未成年人保护 | 心理/控辍类仅"预警不诊断"；数据脱敏；学生聊天内容仅本人/监护教师可见 |
| 密钥管理 | 全部 .env 注入（JWT 密钥≥256bit 随机、Redis 密码、LLM Key），禁止硬编码与日志输出；.env 不入库 |

### 5.6 安全约束头脑风暴扩展项（在用户清单之外追加）

1. Refresh Token 轮换 + 复用检测（防 Token 窃取重放）
2. 登录失败账号锁定 + 验证码强制（防撞库）
3. 会话设备指纹 + 异地登录通知与踢出（防会话劫持）
4. 幂等键机制（AI 生成接口防重复扣费/重复生成）
5. 非ce 防重放（高风险接口时间戳+一次性 nonce）
6. 服务端二次输出清洗（XSS 纵深防御第二层，即使前端被绕过）
7. AI 输出 Schema 强校验 + 失败降级（防 Prompt 注入产生恶意 HTML/JS）
8. 苏格拉底辅导服务端规则层（防"给答案"越界 + 敏感词过滤）
9. 文件 SHA-256 校验去重 + 下载鉴权（防上传漏洞/盗链）
10. 全站响应头隐藏框架版本（X-Powered-By 移除、Server tokens off）
11. 审计日志与业务日志分离 + 轮转（防日志文件无限膨胀）
12. 账号枚举防护：登录/重置密码接口对不存在用户名返回与"密码错误"相同文案 + 相同耗时（恒定时间响应）
13. 密码修改/重置后强制吊销所有既有会话（防撞库后持续劫持）
14. 管理员操作二次确认（前端确认框）+ 审计强制记录
15. SQLite WAL + 写串行化（防写锁异常导致 500）
16. 演示数据与生产数据隔离标记（Demo 角标数据源字段），评委演示与真实数据可切换

## 6. AI 适配层设计

```
AiService.generate(kind, payload)
  ├─ kind: lesson|paper|grading|researcher|micro|speech|tutor|qa|tips|family|backToSchool|titleOrganize
  ├─ Provider 接口: chat(messages, {temperature, maxTokens, jsonMode}) → { content, raw }
  ├─ OpenAICompatProvider  (baseUrl+apiKey 可配: DeepSeek/通义千问/OpenAI/本地兼容服务)
  │    - 系统提示词模板库（每 kind 一套，含 JSON 输出 schema 约束 + 数据来源引用要求）
  │    - 超时 60s、重试 1 次、失败 → DemoProvider
  ├─ DemoProvider（规则引擎）: 按 kind + 输入参数确定性生成（模板拼接 + 题库/图谱检索），
  │    输出带 dataSource: 'demo' 标记，前端展示"DEMO"角标
  ├─ RAG 检索: textbook_contents_fts(FTS5 关键词) + knowledge_points 图谱扩展 + questions 检索
  │    → 上下文拼接 + 输出 refs（出处引用：教材章节/页码/题号）——满足"可溯源"
  └─ 结构化解析: JSON schema 校验 → 失败重试 → 仍失败降级 Demo
```

- **苏格拉底辅导规则层**：系统提示词三级约束 + 服务端检测器（输出含完整答案模式 → 拦截并改写为引导式追问）
- **认知诊断 BKT 简化模型**：参数（掌握/遗忘/猜测/失误）+ 最近 20 次作答滑动窗口 + 知识点父子传播，确定性计算（固定种子），输出掌握度/置信度/错因/证据题，每次作答回流更新（数据闭环）
- **OCR 适配层**：接口定义 `recognize(image)`，默认规则引擎模拟（打 Demo 角标），可配置接入真实 OCR 服务

## 7. 性能方案

| 项 | 措施 |
|---|---|
| 前端加载 | 4 端独立入口；TS 按页面分包 + 动态 import 懒加载；ECharts 单例按需初始化；构建产物 minify + gzip；静态资源 nginx 强缓存（immutable） |
| 前端渲染 | 列表虚拟滚动（学生/预警/日志长列表）；接口请求缓存（GET 同参数 30s）；并发请求合并（同 key 共享 Promise）；防抖节流（搜索/筛选）；防重复提交（按钮锁定+幂等键） |
| 后端 | Redis 缓存热点（班级看板/区域看板/资源库列表 60-300s，失效由写操作主动清）；分页上限 100；数据库索引（§3.11）；慢查询日志（>500ms 告警）；N+1 防护（QueryBuilder 联查） |
| 网络 | 全站 HTTPS + HTTP/2（Nginx）；上传走独立资源域并行 |
| 目标 | Lighthouse 性能/最佳实践/可访问性 ≥92 |
