# 教师端「智能体工作台」一体化改造 — 设计方案（最终版）

> 日期：2026-08-16（更新：跳转式最终方案）
> 目标：教师端保持原有 UI 布局与功能页，各功能作为「预设」在教师端表单中设计好参数，点「发送给智能体」后**自动跳转到独立智能体对话页（agent.html）**，以流式展示思考过程与工具链调用；UI 与教师端一致。
> 约束：最小化修改、复用现有 agent 基础设施（SSE / agent 图 / 工具注册 / 轨迹回放 / 文档生成）、不引入新框架。

---

## 1. 最终交互形态

```
教师端主控制台（teacher.html）              智能体对话页（agent.html）
┌───────────────────────────────┐          ┌────────────────────────────────┐
│ 侧边栏（原布局保留）            │          │ 侧边栏                         │
│ ├ 工作台                       │  发送     │ ├ 新建会话 / 搜索 / 任务历史    │
│ │  └ 班级学情看板               │ ────────► │ 中部                           │
│ ├ 智能体工作台（分组）          │ 自动跳转   │ ├ 会话头（对话/轨迹 tabs）      │
│ │  ├ 一键备课    ──► 表单       │          │ ├ 流式对话区                    │
│ │  ├ 一键组卷    ──► 表单       │          │ │  ├ 思考折叠卡                 │
│ │  ├ 微课脚本    ──► 表单       │          │ │  ├ 工具调用卡 IN/OUT          │
│ │  ├ AI 教研员   ──► 表单       │          │ │  ├ 文本流 / 交付卡 / 下载     │
│ │  └ 基本功补强  ──► 表单       │          │ └ 输入框                       │
│ ├ 资源与材料                    │          └────────────────────────────────┘
│ │  ├ 教学资源库 / 拍照转教案     │
│ │  ├ 家长会材料包 / 开学材料包   │
│ │  └ 职称材料整理               │
│ └ 协作教研（集体备课保留）       │
└───────────────────────────────┘
```

核心链路：**教师端原功能页表单填好参数 → 点「发送给智能体」→ 表单值序列化为任务文本存入 sessionStorage → 跳转 agent.html → agent 页自动发送并流式渲染**。

## 3. 教师端改动

### 3.1 侧边栏分组

- 原「教学提效 / AI 教研 / 资源与材料」重组为：
  - **工作台**：班级学情看板（保留）
  - **智能体工作台**（新分组，紫色小机器人标识）：一键备课、一键组卷/分层作业、微课脚本、AI 教研员、基本功补强
  - **资源与材料**：教学资源库、拍照转教案、家长会材料包、开学材料包、留守儿童沟通（原页）、职称材料整理
  - **协作教研**：集体备课（保留）
- **删除**：一键批改（`#page-grading` section + legacy `showGrading` + CSP 白名单）

### 3.2 各功能页「发送给智能体」按钮

所有智能体相关功能页保持**原 UI 与表单**不变，仅把原「生成」按钮替换为「发送给智能体」（`data-send-agent="key"`）：

| 页面 | 按钮位置 | 收集字段（data-field） |
|---|---|---|
| 一键备课 | 表单底部主按钮 | subject/grade/bookVersion/topic/periodCount/duration/adaptation/supplementary |
| 一键组卷 | 页头 head-actions | subject/unit/choice/blank/solve/layerMode + 下载 Word/PDF 按钮 |
| 微课脚本 | 表单底部主按钮 | topic/duration/style/format |
| AI 教研员 | 各 tab 主按钮 | res0: sourceContent；res1: 固定话术任务 |
| 基本功补强 | head-actions「交给智能体」 | 固定自评模板（与诊断向导并存） |
| 教学资源库 / 拍照转教案 / 家长会材料包 / 开学材料包 / 职称材料整理 | head-actions「交给智能体」 | 固定模板 / 页面表单（parentmeet: theme/duration/audience/kp*） |

### 3.3 发送逻辑（teacher-main.ts）

```ts
const SEND_AGENT: Record<string, (form) => string> = { lesson, paper, micro, res0, res1, skills, library, ocr, parentmeet, backtoschool, title };
// 点击 data-send-agent → collectForm(pageId) → task = SEND_AGENT[key](form)
// sessionStorage.setItem('xy.agent.task', task) → location.href = 'agent.html'
```

## 4. agent 页改动

`agent.html` / `agent-main.ts` 仅增加一段：

```ts
const pendingTask = sessionStorage.getItem('xy.agent.task');
if (pendingTask) { sessionStorage.removeItem(...); setTimeout(() => controller.sendTask(pendingTask), 120); }
```

- 不新增预设面板/表单（预设设计在教师端完成）
- 对话流式渲染、轨迹回放、文件下载全部复用既有能力

## 5. 后端改动

### 5.1 组卷 Word/PDF 下载（新增）

- `teacher.controller.ts`：`GET /papers/:id/download?format=docx|pdf`（仅 @Roles + @RateLimit，与 files 下载一致，不带 ReplayProtected）
- `teacher.service.ts`：`downloadPaper()` — 组装试卷 markdown（题目/分层/答案解析）→ `office.generateDocument` → 返回 downloadUrl
- `teacher.module.ts`：imports 增加 `OfficeModule`（office 已 exports OfficeService）

### 5.2 demo 意图扩展（agent-graph.ts）

- `detectIntent` 增加：微课/脚本/发言稿/家长会/开学/材料包/职称/归档/补强/训练计划 → `generate`
- demo `generate` 分支按关键词路由：微课→generate_document；组卷→generate_paper+generate_document；教研→researcher_comment；发言稿/材料包→generate_document；默认→备课流水线（保留）
- `buildDemoFinalText` 增加 paper/doc 交付文案
