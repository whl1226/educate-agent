# 乡芽 · 乡镇教育智能体 — 部署手册

## 1. 系统要求

| 组件 | 要求 |
|---|---|
| Node.js | ≥ 18（开发验证环境 20.18.0） |
| 数据库 | SQLite 内置（better-sqlite3，WAL 模式），零安装 |
| Redis | 可选（未配置时自动降级为进程内内存存储，仅限演示） |
| 反向代理 | Nginx ≥ 1.20（生产建议，HTTPS 终结） |
| 进程管理 | PM2（生产建议） |

## 2. 目录结构

```
无界应用-教育智能体/
├── server/               # NestJS 后端
│   ├── src/              # 源码（modules/ 按角色分模块）
│   ├── data/             # SQLite 数据库 + 测试脚本
│   └── dist/             # 编译产物
├── public/               # 前端静态资源（4 个 HTML + legacy 脚本 + 打包产物）
│   └── assets/app/*.js   # esbuild 打包的入口脚本（构建生成）
├── src/frontend/         # 前端 TS 源码（core/ + entries/）
├── build-frontend.mjs    # 前端构建脚本
└── docs/                 # 本文档及设计、API、测试、演示文档
```

## 3. 安装与构建

```bash
# 1) 安装后端依赖
cd server
npm install

# 2) 安装前端构建依赖（项目根目录）
cd ..
npm install --save-dev esbuild puppeteer-core   # puppeteer-core 仅验收测试需要

# 3) 构建后端
cd server
npm run build                # tsc → dist/

# 4) 构建前端（从 server/.env 读取签名密钥注入前端）
cd ..
node build-frontend.mjs      # 产物 → public/assets/app/*.js
```

## 4. 环境变量（server/.env）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | 3000 | 监听端口 |
| `DB_PATH` | `data/xiangya.db` | SQLite 路径（相对 server/） |
| `SIGNING_SECRET` | 见 .env | 请求签名 HMAC 密钥（**生产必须更换为随机值**，且前后端保持一致，前端经构建注入） |
| `JWT_SECRET` | 见 .env | JWT 签发密钥（生产必须更换） |
| `JWT_EXPIRES_IN` | 900s | Access Token 有效期 |
| `REFRESH_SECRET` | 见 .env | Refresh Token 密钥 |
| `REDIS_HOST/PORT` | - | 可选，配置后启用 Redis 限流与缓存 |
| `LLM_PROVIDER` | demo | `demo` 或 `openai-compatible` |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | - | 接入 OpenAI 兼容服务后获得完整生成能力 |
| `CORS_ORIGINS` | 见 .env | 允许的跨域来源 |

> 安全提示：`SIGNING_SECRET` 会被注入到前端 bundle，属客户端可读。生产建议改为
> 「前后端共享密钥 + 服务端短时白名单」方案，或升级为设备指纹 + 短时挑战码。

## 5. 启动

```bash
cd server
node dist/main.js
# 或生产：pm2 start dist/main.js --name xiangya
```

健康检查：`GET /api/v1/system/health` → `{"code":0,"data":{"status":"ok"}}`

## 6. Nginx 反向代理示例

```nginx
server {
  listen 80;
  server_name your-domain;
  client_max_body_size 110m;            # 允许 100MB 视频上传

  location /api/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
  location / {
    proxy_pass http://127.0.0.1:3000;    # 静态资源由 Nest 提供
  }
}
```

生产建议：Nginx 终结 HTTPS（TLS 1.2+），并将 `uploads/` 目录纳入备份。

## 8. 升级与回滚

- 后端：`npm run build` 后 `pm2 restart xiangya`；数据库结构变更使用 TypeORM 迁移（synchronize 关闭时需手工迁移）。
- 前端：`node build-frontend.mjs` 后刷新静态资源即可；legacy 原型脚本与打包入口共存，回滚只需替换 `assets/app/*.js`。

## 9. 已知边界（演示模式）

- 无 LLM Key 时 AI 生成为规则模板（demo），接入 OpenAI 兼容服务后自动切换真实生成。
- 语音留言为文本模拟（无真实录音），OCR 返回占位文本。
- 未配置 Redis 时限流/缓存为进程内存，重启清零。
