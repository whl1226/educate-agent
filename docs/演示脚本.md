演示总时长约 15 分钟。前置：服务已启动（`cd server && node dist/main.js`），浏览器访问 `http://localhost:3000/login.html`。

## 0. 开场（30 秒）

> 「乡芽」—— 面向乡镇学校的 AI 教育智能体：四端（教师/学生/家长/管理）一库，
> 覆盖备授课、学情、家校、区域治理全链路；未接入大模型 Key 时以规则模板演示，
> 换 Key 即切真实 AI。先看登录安全：验证码 + 签名 + 一次性 Nonce。

## 1. 教师端（约 4 分钟）

1. 登录：`wangxiulan / Demo@2026xy` → 进入工作台。
2. 首页 KPI：**43 人班级**、近 7 日作答、准确率、待批改份数（真实接口数据）。
