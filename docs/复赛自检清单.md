## 一、九项能力自检

### 1. 任务理解（5 类意图识别）

- [ ] 验证方法：在 `server/src/modules/agent/agent-graph.ts` 运行单测（`detectIntent` 用例），并用 5 类话术各在 agent.html 发一次：
  - `diagnose`：「帮我诊断学习薄弱点」
  - `teach`：「我的学习计划」
  - `generate`：「帮我备一节五年级语文课：草船借箭」
  - `knowledge`：「草船借箭讲了什么故事？」
  - `admin`：「看看区域预警情况」
- [ ] 通过标准：LLM 模式各任务被正确归类且执行对应工具；demo 模式 5 类话术触发对应规则分支；运行历史中 `intent` 字段标签正确。

### 2. 流程编排（工具调用顺序与依赖）

- [ ] 验证方法：诊断类任务观察工具序列；知识类任务观察是否先检索后作答；教师备课任务观察教案生成参数完整。
- [ ] 通过标准：编排顺序符合业务依赖（先 `run_diagnosis` 再 `get_error_book`/`get_study_plan`；知识回答前必有 `search_knowledge`）；无循环调用、无无效重复；运行详情中每个工具卡片带参数。

### 3. 工具调用（卡片展示参数/结果/耗时/状态）

- [ ] 验证方法：展开任意工具卡片，核对四要素；故意触发一个失败场景（如不可用数据源或超时）。
- [ ] 通过标准：卡片展示 `参数`（可展开 JSON）、`结果`（可展开 JSON）、`耗时 ms`、`状态`（✓ 完成 / ✗ 失败）；失败卡片红色标注并可展开错误信息；`tool_result` 消息 status 与卡片一致。

### 4. 知识增强（引用 + 防幻觉）

- [ ] 验证方法：知识类提问后检查最终回答的 refs；用「草船借箭」「祖父的园子」等种子教材话题（人教版 2019 审定）验证检索命中；运行 `npm test` 中 `hybrid-retriever` 与 `refs-verify` 用例。
- [ ] 通过标准：回答带 `chunk:xxx` 引用且**通过 `verifyRefs` 校验**（引用对应的 chunk 真实存在于 `knowledge_chunks`）；无效引用被剔除并在摘要提示；`knowledge_chunks` 表非空（`SELECT COUNT(*) FROM knowledge_chunks`）。

### 5. 多轮交互（checkpoint 记忆）

- [ ] 验证方法：知识类问题后立即追问（如「那曹操为什么会上当？」）；重启服务前再验证一次。
- [ ] 通过标准：追问回答承接上下文，不重复解释；SQLite checkpoint 落库正常（服务日志无「本轮记忆关闭」警告）；同一线程消息顺序正确。

### 6. 结果交付（可操作、可追溯）

- [ ] 验证方法：诊断任务完成后查看交付卡片；点击左侧任务历史 → 右侧运行详情回放。
- [ ] 通过标准：交付文本包含掌握度数值、薄弱点名称、下一步建议（可操作）；`GET /api/v1/agent/runs/:id` 可回放全链路（思考/工具调用/参数/结果/耗时/final）；非管理员只能看自己的运行（越权返回 403 语义错误）。

### 7. 可复现（同一输入两次结果一致）

- [ ] 验证方法：同一账号、同一任务连续执行两次（demo 模式）；对照两次运行的工具序列与数值。
- [ ] 通过标准：demo 模式两次事件流与工具结果一致（确定性哈希 embedding + 固定规则）；LLM 模式两次结果语义一致（允许表达差异）；`npm test` 中 BKT/检索/SOCRATIC 相关用例全绿。

### 8. 失败处理（needs_human / 降级）

- [ ] 验证方法：制造工具失败（临时停用数据或注入错误）观察状态；无 LLM Key 环境（`LLM_PROVIDER` 缺省）整体跑一遍。
- [ ] 通过标准：工具失败 → 运行状态 `needs_human` 且事件流不中断；LLM 不可用 → 自动规则降级（demo 模式）且事件流完整；工具超时 30s 自动中断并标记 error；`agent_runs.status` 含 `success / needs_human / failed / running` 四态。

### 9. 合规（演示数据、授权、边界）

- [ ] 验证方法：检查种子数据来源标注（教材内容标注「教材内容·教育用途」）；家长端周报视图；交付话术。
- [ ] 通过标准：演示数据带"演示数据"角标说明；家长端数据脱敏且周报说明授权来源；AI 结论含「诊断结果仅供参考，不替代教师评价」类边界声明；`.env` 不提交仓库（见 `.gitignore`）。
