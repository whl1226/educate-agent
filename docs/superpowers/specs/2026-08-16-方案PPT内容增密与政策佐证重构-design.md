# 方案PPT v5 重构设计：内容增密 + 图片/政策佐证

- 日期：2026-08-16
- 状态：已获用户方向批准（内容为王 + 网络图片 + 政策官网截图，三项政策已选定）
- 范围：`初赛提交材料/方案PPT.html`（24 页）的概念页与收尾页

## 1. 背景与根因

用户连续两轮反馈概念页"空白太多、AI 味重、只是被拉长、没有解决实际问题"，要求竞赛级水准。

**根因诊断**：384×216mm 是很大的 16:9 画布，概念页的"内容实体"只够填 60% 面积。上一版用 `flex:1` / `align-content:stretch` / `margin-top:auto` 只把**容器**拉高、间距撑大，元素之间空白更大——视觉密度没有提升。

**已确认方向**：内容为王——每页补足真实内容实体，让空白自然消失；辅以网络图片与政策官网截图补情境与证据。

## 2. 设计原则（不可违反）

1. **内容为王**：每页补真实内容实体（数据条/清单/流程/轨迹/时间线），不靠装饰填充。
2. **零编造**：所有数字与术语必须来自产品既有资产——38 项能力（14/12/5/7）、16 个工具、7 类数据源 D1–D7、BKT/ZPD/ReAct/SSE 协议、39 项测试、MIT 许可、0 授权费、128 条教研规则、演示剧本真实交互（王秀兰备课、赵小军下钻、1,286 次作答、18 校 6,842 学生等）。
3. **禁 flex:1 拉伸**：版面一律用栅格铺满，禁止再拉容器高度。
4. **图片版权**：仅用可商用图库（Unsplash/Pexels）或政府官网新闻图，每张标注来源；禁用版权图与 AI 生成图。
5. **政策截图真实性**：必须真实访问官网抓取，核对文号，配 caption（文件名·文号·发布机构·日期·网址）。
6. **风格延续**：新元素沿用"田园编辑部"语言——数据条（白底绿字）、清单卡（细线边框）、分区线；不引入新风格，避免 AI 味。

## 6. 视觉承载规范

- 每页结构：kicker 标题 + 主体栅格 + 页脚，栅格铺满画布。
- 新增元素样式：数据条（白底+绿字 10.5pt）、清单卡（细线边框+浅底）、caption 条（9pt 灰字）、政策截图框（细边框+caption）。
- 截图区域统一 max-height 约束，与文本并排，避免压占正文。

## 8. 风险与对策

- 官网反爬/改版 → 备选源 + caption 注明。
- 图库下载失败 → 本地先下载后引用，不依赖线上加载。
- OCR 对政策小字误读 → 截图区域裁剪放大，EXPECT 不含政策截图内小字。
- 内容增加导致溢出 → 每页栅格 + 审计兜底，禁止 flex:1 硬撑。
