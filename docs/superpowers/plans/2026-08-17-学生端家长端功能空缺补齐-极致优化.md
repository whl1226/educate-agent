# 学生端 + 家长端功能空缺补齐与极致优化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把乡芽原型学生端与家长端所有"假功能/空缺/未真正实施"的入口补齐为真实 API 闭环，并做一轮移动端极致 UX 优化。

**Architecture:** 前端沿用现有模式：静态 `public/*.html`（含 legacy JS 假行为）+ `src/frontend/entries/*-main.ts`（真实 API 绑定，通过 `preempt()` 在 document 捕获阶段覆盖 legacy onclick）。服务端 NestJS：student.controller/parent.controller 已有全部业务接口，缺的仅是个别返回字段增强。权限 preview 已由 X-Preview 头放行（上次已修复）。

**Tech Stack:** NestJS + TypeORM/SQLite、原生 TS + esbuild（build-frontend.mjs）、Playwright（验证）、vitest（服务端单测）。

function bindCoursePlay() {
  preempt('#coursePlayBtn', (btn) => {
    void (async () => {
      btnBusy(btn, true);
      try {
        const courses = await get<any[]>('/family-courses');
        const first = courses?.find((c) => c.status !== 'done') || courses?.[0];
        if (!first) {
          toast('本周课程已全部学完，真棒！');
          return;
        }
        await post('/family-courses/' + first.id + '/complete');
        toast('已学完《' + first.title + '》，打卡成功');
        loadCourses();
        const hero = document.querySelector('#view-family .section-title');
        if (hero && courses.length) {
          const done = courses.filter((c) => c.status === 'done').length + 1;
          const sub = hero.nextElementSibling as HTMLElement | null;
          if (sub) sub.textContent = `本周已学 ${done}/${courses.length} 门 · 亲子共学进行中`;
        }
      } catch (e: any) {
        toast(e?.message || '操作失败');
      } finally {
        btnBusy(btn, false);
      }
    })();
  });
}
```

function bindVoice() {
  preempt('#voiceSend', () => {
    void (async () => {
      const inp = document.getElementById('voiceInput') as HTMLInputElement | null;
      const text = (inp?.value || '').trim();
      if (!text) { toast('先写一句话再发送'); return; }
      if (inp) inp.value = '';
      await sendVoiceMsg(text, 5);
    })();
  });
  preempt('#recordBtn', (btn) => {
    void (async () => {
      toast('语音录制即将上线 · 先试试文字留言');
      btnBusy(btn, true);
      setTimeout(() => { btnBusy(btn, false); }, 800);
    })();
  });
}

async function sendVoiceMsg(text: string, durationSec = 5) {
  try {
    const msg = await post<any>('/voice-messages', { text, durationSec });
    const chat = document.getElementById('voiceChat');
    if (chat && msg?.id) {
      const d = document.createElement('div');
      d.className = 'msg voice-me';
      d.innerHTML =
        '<div class="ava"><span class="iconify" data-icon="ph:user"></span></div><div class="bub">' +
        esc(text) +
        '<div style="font-size:10px;color:rgba(255,255,255,.7);margin-top:6px">已发送 · 小雨会收到提醒</div></div>';
      chat.appendChild(d);
      d.scrollIntoView({ behavior: 'smooth', block: 'nearest' });
    }
    toast(msg?.ack || '留言已发送');
  } catch (e: any) {
    toast(e?.message || '发送失败');
  }
}
```

function bindReminds() {
  const KEY = 'xy_parent_reminds';
  const map: Record<string, string> = { remindWeekly: 'weekly', remindVoice: 'voice', remindMeeting: 'meeting' };
  const load = () => {
    let saved: Record<string, boolean> = {};
    try { saved = JSON.parse(localStorage.getItem(KEY) || '{}'); } catch { /* noop */ }
    for (const [id, key] of Object.entries(map)) {
      const sw = document.getElementById(id)?.querySelector('.switch');
      if (sw) sw.classList.toggle('on', saved[key] !== false);
    }
  };
  for (const [id, key] of Object.entries(map)) {
    document.getElementById(id)?.addEventListener('click', () => {
      const sw = document.getElementById(id)!.querySelector('.switch')!;
