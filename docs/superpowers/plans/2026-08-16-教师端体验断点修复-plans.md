- [ ] **Step 1: 在 teacher-main.ts 添加 bindGlobalControls() 并挂到 boot()**

在 `src/frontend/entries/teacher-main.ts` 的 boot() 中 `bindSendAgent();` 之前加入：

```ts
/** 全局控件绑定：radio-pill / switch / opt-card（teacher.html 内联 onclick 多不满足 CSP 层 fn(args) 正则而失效，统一在此绑定） */
function bindGlobalControls() {
  document.querySelectorAll('.radio-pill > span').forEach((el) => {
    if ((el as HTMLElement).dataset.bound === '1') return;
    (el as HTMLElement).dataset.bound = '1';
    el.addEventListener('click', () => {
      const pill = el.parentElement;
      if (!pill) return;
      pill.querySelectorAll('span').forEach((s) => s.classList.remove('on'));
      el.classList.add('on');
    });
  });
  document.querySelectorAll('.switch').forEach((el) => {
    if ((el as HTMLElement).dataset.bound === '1') return;
    (el as HTMLElement).dataset.bound = '1';
    el.addEventListener('click', () => el.classList.toggle('on'));
  });
}
```

注意：`.opt-card` 已有多数页面内联 `onclick="selQ(...)"`（经 CSP 层绑定），**不要**在此重复绑定，避免双触发。
