## 4. 安全自检（security-check.js，11/11）

见《安全设计说明》§7 明细。另含两个自检中发现并已修复的缺陷：

1. `AllExceptionsFilter` 未处理 class-validator 的数组 message → 校验失败误报 50001「系统繁忙」；已修复为映射 40001（实测注入载荷返回「40001 用户名格式不正确」）。
2. `files.service` 上传目录 `server/public/uploads` 与静态挂载 `/uploads` 不一致 → 已统一为 `server/uploads`。

## 5. 登录链路专项（smoke-login.js）

CSRF 初始化 → 签名登录（Cookie 落盘）→ me → refresh 换新 Access → 伪造 Cookie refresh 被拒（403），全部通过；同时验证前端 `request.ts` 签名拼接（含 `/api/v1` 前缀）与服务端校验一致。

## 6. 环境噪音说明

- iconify 公网图标 CDN 离线报错（api.iconify.design 等）为验收环境网络噪音，页面功能不受影响（图标已降级为占位）。
- 验收脚本运行前需重启服务清空内存限流计数（login 10 次/15 分钟），避免误触发 429。
